# ethanmartinez.dev

Personal site. Astro, no client-side JavaScript, deployed to GitHub Pages.

- `src/content/projects/*.md` — one file per project. Frontmatter feeds the home page list; the body is the case study page.
- `src/pages/index.astro` — the home page.
- `src/layouts/Base.astro` — HTML shell and design tokens.

```sh
npm install
npm run dev
```
